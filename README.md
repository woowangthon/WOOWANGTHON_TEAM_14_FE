# WOOWANGTHON_TEAM_14_FE — Handoff 프론트엔드

**빠진 인수인계를 AI가 먼저 묻습니다.**
동아리·학생회 임원이 바뀔 때, 전임이 문서에 적지 못한 내용을 AI가 질문으로 끌어내고, 전임이 확인한 내용만 후임에게 전달하는 서비스의 프론트엔드입니다. (2026 AI 우왕톤, 팀 투게더)

- 서비스: https://woowangthon-team-14-fe.vercel.app
- 시연 영상: https://youtu.be/ug_3mFLfXkw
- 백엔드 저장소: https://github.com/woowangthon/WOOWANGTHON_TEAM_14_BE

## 사용 흐름

1. **시작** — 조직 이름과 담당 업무를 입력합니다.
2. **자료 올리기** — 회칙·공지(PDF·TXT, 여러 개 가능)를 올리면 AI가 업무 목록을 뽑습니다.
3. **항목 고르기** — 전임이 다룰 업무를 체크로 고릅니다.
4. **카톡에서 내용 뽑기** — 단톡 대화(TXT)를 올리면 업무별 사실(출처 포함)과 빠진 정보를 찾습니다.
5. **분석 결과** — 업무마다 필수 정보 6가지(시기·연락 경로·판단 기준·자주 틀리는 점·미리 할 일·배경)의 상태를 체크표로 봅니다.
6. **질문** — 빠진 정보를 질문 카드로 만들어 3단계(사실·예외·사례)로 묻고, 답을 정리한 초안을 맞음·수정·삭제로 확정합니다.
7. **문서** — 확정된 기록만 인수인계서가 됩니다. 후임이 질문하면 확정된 원문을 출처와 함께 보여 주고, 없으면 "기록 없음"과 함께 전임에게 질문을 전달합니다.

## 기술

React 19 · Vite · TypeScript · Tailwind CSS 4 · react-router-dom · Vitest + Testing Library · Pretendard

- `src/api/httpApi.ts` — 실제 백엔드(FastAPI) 연결. 에러 본문(`error`)을 화면에 맞게 변환합니다.
- `src/api/mockApi.ts` — 서버 없이 가짜 응답으로 동작하는 개발·테스트용 모드입니다. **제출한 배포본은 실제 백엔드에 연결**되어 있습니다.
- `src/pages` — 시작·자료·질문·문서 화면, `src/components` — 체크표, 항목 편집, 폴더 화면 등.

## 실행

Node 22 이상 권장 (개발은 Node 24에서 진행).

```bash
npm install
npm run dev      # 개발 서버
npm test         # 테스트 (214개)
npm run build    # 타입 검사 + 빌드
```

실제 백엔드에 연결하려면 `.env.local`에 아래를 넣습니다. 없으면 모킹 모드로 동작합니다.

```
VITE_API_BASE=https://woowangthon-team-14-be.onrender.com
```

백엔드는 무료 서버라 잠들어 있으면 첫 요청이 50초 이상 걸립니다. 시연 전에 `/health`를 한 번 열어 깨워 주세요.

## 시연 자료

백엔드 저장소의 `fixtures/demo/rules.txt`(회칙·공지)와 `kakao.txt`(대화)는 팀이 만든 **가상 샘플**입니다. 실제 동아리 대화로 검증한 수치는 발표 자료에 있으며 원문은 개인정보 때문에 공개하지 않습니다.

## 알려진 한계

- 후임 질문 검색은 단어가 겹쳐야 찾습니다(예: "예약"과 "대관"은 연결하지 못함).
- 로그인이 없고, 스캔 PDF·HWP는 읽지 못합니다.
- 질문이 전임의 새 노하우를 실제로 끌어내는지에 대한 사용자 측정은 하지 못했습니다.
